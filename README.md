# FermaQED

Rubyで実装した自作プログラミング言語（インタプリタ）です。  
大学の最終課題として開発しました。

---

## 概要

FermaQEDは、プログラミング言語の内部構造を理解することを目的に開発した独自言語です。  
字句解析・構文解析・実行処理を一から実装し、基本的な演算や制御構文を実行できる仕組みを構築しました。

---

## 主な機能

- 四則演算（+ / - / * / /）
- 配列による変数管理
- 条件分岐（if）
- ループ処理（while）
- QEDを用いた独自構文

---

## 構成

### 字句解析（Lexer）
ソースコードをトークンに分解

### 構文解析（Parser）
トークン列から構文構造を生成

### 実行処理（Interpreter）
構文に基づいてプログラムを実行

---

## 技術的なポイント

- 言語処理系の基本構成（Lexer / Parser / Interpreter）を実装
- 独自の文法設計
- 制御構文（if / while）の実装
- 配列ベースの変数管理
