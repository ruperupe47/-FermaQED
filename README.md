# -FermaQED
大学の課題で作成した自作言語であるFermaQEDのプログラムとチュートリアルなどを一部修正して公開したもの

## 概要

FermaQEDは、プログラミング言語の内部構造（字句解析・構文解析・実行処理）を理解することを目的として設計・実装した独自言語です。  
シンプルな構文でありながら、基本的な演算や制御構文を実行できます。


## 主な機能

- 四則演算（+ / - / * / /）
- 配列ベースの変数管理
- 条件分岐（if）
- ループ処理（while）
- 文末に "QED" を用いた独自構文


## 構成

本インタプリタは以下の3つの要素で構成。

### 1. 字句解析（Lexer）
ソースコードをトークンに分解

### 2. 構文解析（Parser）
トークン列から構文構造を生成

### 3. 実行処理（Interpreter）
構文に基づいてプログラムを実行


## 技術的なポイント

- 字句解析・構文解析・実行処理までを一貫して実装
- 独自の文法設計
- if文・while文による制御構文の実装
- 配列を用いた変数管理機構
